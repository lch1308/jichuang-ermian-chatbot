# 安装与配置边界

这是已集成源码的发布副本，不是拷贝工作电脑的运行环境。安装应在新目录、独立环境和测试房间中进行。

## 环境

- MaiBot：快照项目版本 1.2.5，Python >=3.12；依赖以本目录的 pyproject.toml 与锁文件为准。
- Open-LLM-VTuber：快照项目版本 1.2.1，Python >=3.10 且 <3.13。与 MaiBot 分别创建虚拟环境，不能混装全部依赖。
- StoryRoom：FastAPI、Uvicorn、Pydantic、httpx、Pillow；先使用 Python 3.12 验证。
- 本地声带：当前 voice/server.py 使用 CUDA 与 Qwen3-TTS。没有相应 GPU、权重和合法声音资源时，保留其他已有 TTS 服务，不宣称可直接切到 CPU 运行。

## 必须自行准备

1. 模型服务、可用模型 ID 与本机 API Key。
2. QQ 登录环境及需要响应的账号／群配置。源码检查不需要登录 QQ。
3. 两套 Live2D 资源与各自表情映射、遵循原许可的 Cubism Core。
4. 如使用本地 ASR/TTS，准备各自模型、依赖与服务配置。
5. 异地连接地址及每台机器自己的角色凭据。localhost 只指向当前电脑。

## 配置位置

所有真实配置都是本地文件，不提交仓库：

- MaiBot 的 config/bot_config.toml、config/model_config.toml 和各插件 config.toml。
- VT 的 conf.yaml、model_dict.json 和本机角色配置。
- 实时插件 settings.json、runtime-location.json、管理员 facts.json。
- StoryRoom 的 local-config.json、model-config.json、.runtime 数据与主持／玩家凭据。
- 声带 voice_config.json、.runtime 令牌和声音参考文件。

先阅读示例与各自 schema，再在本机生成或填写配置。示例中的路径和模型名不保证适用于另一台电脑。

## 源码与资源边界

为避免带出个人图像和受单独许可约束的资源，本快照只整理了文本源码与已安装 VT 的文本前端包。管理页构建所需的二进制图片／字体、VT 的 Cubism Core 与模型资源没有随包提供；构建或部署前需按相应上游版本准备。不会把本机现有资源的“安装成功”当作新电脑已经可运行。

本发布不是跨版本一键升级器。已有机器人或同伴主机需要停机备份，比较宿主源码、插件 manifest 与 SDK 版本，并在测试目录验证后再切换。不要热覆盖正在工作的插件，不清空旧记忆，不覆盖同伴声音配置。

## 测试顺序

先启动无模型的 StoryRoom 主持界面，再连接一个 PC，随后连接两个 PC，检查文字、检定与记忆；然后检查表情和语音。AI 主持与 COC7 迁移是后续测试项目。真实模型、麦克风、异地两台电脑和 QQ 群实发，需要单独验收。
